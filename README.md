# Multiscale-stepwise-learning-network-for-seismic-impedance-inversion

This repository provides the source code, example data, and reproduction instructions
for the multiscale stepwise learning network for seismic impedance inversion.

## Data availability

The field 3D seismic and well-log data used in the manuscript are proprietary
and cannot be publicly released. Example data are provided for demonstrating
the workflow and reproducing the main procedures.

## Environment

- Python 3.x
- PyTorch
- PyWavelets
- NumPy
- SciPy

Install dependencies using:

pip install -r requirements.txt
